把需求文档变成画像，
把画像变成可审核的候选人名单

面向专家招募与审核的 DSH 工作台：左侧项目导航、中间原生 Agent 对话、右侧业务面板。解析需求 → 生成画像 → 匹配专家 → 人工审核，全部在同一个界面里完成。

打开交互原型 → 查看源码

它解决什么

不是聊天机器人，而是一张能推进项目的工作台。

01

需求 → 画像

从项目需求文档中抽取行业、规模、地域、角色、预算与排除条件，形成可编辑、带出处的结构化画像。

02

画像 → 候选人

按画像在候选池中召回专家，给出 AI 判断（推荐 / 待确认 / 建议排除）与匹配理由，而不是只有一个分数。

03

人工审核闭环

批量通过、排除、恢复待确认；审核结果留痕，未读变动在卡片上以 +N 提示，滚动时监控卡片始终置顶。

安装

需要一台已安装 DSH 的机器；插件跟随 profile 加载。

dsh plugin --profile desktop add link:/path/to/expert-ops/plugin

安装后重启 dsh web，左侧边栏出现「专家运营」入口。本页是静态展示：插件依赖 DSH 宿主的会话、工具与本地存储，无法单独运行在 Pages 上；上面的交互原型是纯前端演示，数据为示例。
